## Project Summary

HYDROSMART is an IoT-based hydroponics monitoring and water and nutrient quality control system for the Mindoro Horticultural Center (ORMAES). It integrates ESP32-connected sensors, Wi-Fi communication, Firebase Realtime Database, and a Laravel web application. The system monitors pH, electrical conductivity, water temperature, and water level. It also allows an authorized operator to control the nutrient and pH dosing pumps.
